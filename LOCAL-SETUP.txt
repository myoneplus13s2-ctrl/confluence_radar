CONFLUENCE RADAR ON YOUR OWN PC
===============================

This runs the whole site on your Windows PC, the way it ran on Vercel:
the web page, all the tabs, uploads from the capture script, the price
check every 15 minutes (trends, fibs, Prime Oscillator, price alerts),
Telegram alerts and the alarm sound. The database can stay on Neon, or
(recommended, section 7) be copied onto this PC with one click, so the
Neon free plan's monthly compute limit no longer matters.

You open it at:   http://localhost:3000


-----------------------------------------------------------------
1. ONE-TIME SETUP
-----------------------------------------------------------------

Step 1 - Node.js
  You already have it (the capture script uses it). If not, install the
  LTS version from https://nodejs.org

Step 2 - Get the newest files
  Download the repository as a ZIP from GitHub (green "Code" button ->
  "Download ZIP") and unzip it over your current folder:
      C:\Users\seccs\Documents\Tradingview Script\confluence_radar-main
  Your capture\config.json and capture\profiles are not in the ZIP, so
  they are kept.

Step 3 - Collect your keys
  Vercel does not show saved secrets again, so get each one from where
  it came from:

    DATABASE_URL        Your Neon database (starts with postgresql://):
                        https://console.neon.tech -> your project ->
                        Connect -> copy the connection string ("Show
                        password" if it is hidden). To move the database
                        onto this PC instead, do section 7 first.
    GEMINI_API_KEY      Reads screenshots: https://aistudio.google.com/apikey
                        (copy your key, or "Create API key").
    TELEGRAM_BOT_TOKEN  In Telegram: @BotFather -> /mybots -> your bot ->
                        API Token. Do not press "Revoke".
    CRON_SECRET         Not needed on your PC. Leave it empty.

  Optional ones, only if you used them: APP_PASSWORD (site password),
  ANTHROPIC_API_KEY, TELEGRAM_CHAT_ID, ALERT_TZ, GEMINI_MODEL.
  PORT=3000 can be changed if something else already uses port 3000.

Step 4 - Start it the first time
  Double-click  start-local.bat  in the main folder.
  The first time, Notepad opens a file called .env.local. Paste each value
  after its "=" sign, for example:
      DATABASE_URL=postgresql://neondb_owner:....neon.tech/neondb?sslmode=require
      GEMINI_API_KEY=AIza....
      TELEGRAM_BOT_TOKEN=123456:ABC....
  Save (Ctrl+S) and close Notepad, then press a key in the black window.

  The first start installs packages and builds the site. That takes a few
  minutes. When you see

      Site is up: open http://localhost:3000 in your browser.

  open http://localhost:3000 . Click once anywhere on the page so the
  alarm sound is allowed to play.

Step 5 - Point the capture script at your PC
  Open capture\config.json in Notepad and change the "site" line to:
      "site": "http://localhost:3000",
  Save. The hourly "Confluence Radar capture" task now uploads to your PC.
  (If you set APP_PASSWORD in .env.local, "password" in config.json must
  be the same.)


-----------------------------------------------------------------
2. EVERY DAY
-----------------------------------------------------------------

  - Keep the black "Confluence Radar" window open. Minimise it; do not
    close it. Closing it stops the site AND the 15-minute check.
  - The 15-minute price check runs inside that window. Each run prints a
    line like "Price check done in 12s".
  - Everything it prints is also saved in logs\local.log.
  - If the site crashes, the window restarts it by itself after 10 seconds.


-----------------------------------------------------------------
3. KEEP IT RUNNING
-----------------------------------------------------------------

Start by itself after a restart
  Double-click  autostart-on.bat  once. From then on the site starts
  (minimised) every time you sign in to Windows.
  To undo: double-click  autostart-off.bat .

Do not let the PC sleep
  The site, the 15-minute check and the hourly capture only run while
  the PC is awake. Windows Settings -> System -> Power -> "Screen and
  sleep": set "When plugged in, put my device to sleep after" to Never.
  The screen may turn off; that is fine.


-----------------------------------------------------------------
4. AFTER AN UPDATE
-----------------------------------------------------------------

  Close the black window, unzip the new files over the folder (Step 2),
  and double-click start-local.bat again. It notices the new files,
  reinstalls and rebuilds by itself.
  To force a fresh build: open a Command Prompt in the folder and run
      start-local.bat --rebuild


-----------------------------------------------------------------
5. OPEN IT FROM YOUR PHONE (same Wi-Fi)
-----------------------------------------------------------------

  The black window prints a "Network:" address such as
  http://192.168.1.20:3000 . Open that on your phone while on the same
  Wi-Fi. Windows may ask to allow Node.js through the firewall the first
  time: choose "Private networks" and Allow.
  Browsers only allow desktop notifications on http://localhost, so the
  pop-up notifications work on the PC itself, not on the phone address.
  Telegram alerts work everywhere.


-----------------------------------------------------------------
6. IF SOMETHING GOES WRONG
-----------------------------------------------------------------

"DATABASE_URL is missing from .env.local"
    Open .env.local in the main folder with Notepad and paste the value
    (Step 3). Note the file name starts with a dot.

"Node.js is not installed"
    Install it from https://nodejs.org and start again.

"Price check FAILED"
    Read the message after it. A database error means DATABASE_URL is
    wrong; "fetch failed" now and then is the internet or Bitget, and the
    next run 15 minutes later tries again.

The capture log says "could not reach the site at http://localhost:3000"
    start-local.bat is not running. Start it.

Port 3000 is already in use ("EADDRINUSE")
    Another copy is already running (check the taskbar), or another
    program uses the port. Add  PORT=3001  to .env.local and use
    http://localhost:3001 (and the same in capture\config.json).

Neon free plan
    The database pauses itself when idle and wakes on the next request,
    so the first page load after a quiet spell can take a few seconds.
    When the monthly compute allowance runs out, Neon stops answering
    until the next month: move the database to this PC (section 7).


-----------------------------------------------------------------
7. MOVE THE DATABASE ONTO THIS PC (recommended)
-----------------------------------------------------------------

  Your signals, fibs, alerts and settings are copied from Neon once.
  Neon itself is only read, never changed, so you can go back any time.

  Step 1 - Install PostgreSQL (free)
    https://www.postgresql.org/download/windows/ -> "Download the
    installer" -> newest version. Run it and keep the defaults. When it
    asks for a password for the "postgres" user, choose one and WRITE IT
    DOWN. Keep port 5432. Untick "Stack Builder" at the end.
    PostgreSQL then runs by itself in the background, also after a
    restart.

  Step 2 - Copy the data
    Close the Confluence Radar window if it is open.
    Double-click  move-db-to-pc.bat . It asks for:
      - your Neon connection string (only if .env.local does not have
        it yet; see Step 3 of section 1 for where to find it),
      - the postgres password from Step 1,
      - the port (just press Enter).
    It copies everything, checks that the number of signals matches, and
    then changes DATABASE_URL in .env.local to the database on this PC.
    The Neon address stays in .env.local as NEON_DATABASE_URL.

  Step 3 - Start the site
    Double-click  start-local.bat  as usual.

  To go back to Neon: in .env.local, put the NEON_DATABASE_URL value
  after DATABASE_URL= and start start-local.bat again.

  Backups: the data now lives only on this PC. logs\neon-backup.dump is
  the copy taken from Neon. For backups from now on, see section 8.



-----------------------------------------------------------------
8. BACKUPS TO GOOGLE DRIVE
-----------------------------------------------------------------

  Once, install Google Drive for desktop and sign in:
      https://www.google.com/drive/download/
  It adds a drive (usually G:) with a "My Drive" folder. Anything saved
  there is uploaded to your Google Drive by itself.

  Back up now:  double-click  backup-db.bat .
  It saves a file like  confluence_radar-2026-11-20_0400.dump  in
      My Drive\Confluence Radar backups
  Without Google Drive for desktop it saves it in logs\backups instead;
  then upload that file at https://drive.google.com yourself.

  Automatic: while start-local.bat runs, it also makes one backup a day.
  The newest 14 backups are kept and older ones are deleted.

  Another folder: add  BACKUP_DIR=D:\some\folder  to .env.local.

  To restore a backup (only if something went wrong): close the
  Confluence Radar window, open a Command Prompt and run (change 18 to
  your PostgreSQL version and the file name to your backup):
    "C:\Program Files\PostgreSQL\18\bin\pg_restore" -U postgres --clean --if-exists --no-owner -d confluence_radar "G:\My Drive\Confluence Radar backups\confluence_radar-2026-11-20_0400.dump"
  It asks for the postgres password. Then start start-local.bat again.
